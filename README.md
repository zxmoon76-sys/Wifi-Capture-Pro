# 📡 Wifi Capture Pro (Advanced Edition)

**Wifi Capture Pro** is a comprehensive WiFi security auditing framework designed for network administrators and security researchers. It provides an automated interface to interact with wireless adapters, enabling seamless packet capture and security assessment.

---

## 🛠️ Key Features
- 📶 **Automated Monitor Mode:** Switches compatible interfaces into monitor mode instantly.
- 🔍 **Network Enumeration:** Scans and lists all nearby BSSIDs, ESSIDs, and encryption types.
- 🔒 **Handshake Capture:** Specialized engine to capture WPA/WPA2 4-way handshakes.
- ⚔️ **Deauthentication Support:** Built-in deauth mechanism to force reconnections.
- 🛡️ **Security Audit:** Integrated dictionary attack and WPS vulnerability tester.
- 📊 **Professional Reporting:** Generates security reports in JSON format.

## 🚀 Installation & Usage

### Prerequisites
- Python 3.x
- Wireless Adapter (Supporting Monitor Mode)
- Root Access (Sudo)
- `aircrack-ng` suite installed
